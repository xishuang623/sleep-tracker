
# 睡眠追踪器

一个手机端 PWA，两键记录睡眠，自动生成月度日历 + 年度矩阵可视化。

## 安装

手机浏览器打开 → 弹出「添加到主屏幕」→ 确认，即可作为独立 App 使用，**离线可用**。

## 日常使用

| 按钮 | 时机 | 效果 |
|------|------|------|
| 😴 睡觉 | 准备入睡 | 记录入睡时间，顶部实时计时 |
| ☀️ 起床 | 醒来时 | 自动计算时长，生成当天记录 |

- 中午 12 点前入睡，记录归到**前一天**
- **同一天仅保留一条记录**，重复会提示替换

## 查看数据

- **时长 / 熬夜切换** — 顶部按钮，控制日历着色维度
- **月度日历** — 有记录的日子自动着色，**点格子弹详情 + 删除**
- **年度总览** — 12 列 × 31 行矩阵，全年一目了然，点格子同样弹详情

## 颜色刻度

### 时长
| ≤2h | 4h | 6h | 7h | 8h+ |
|-----|----|----|----|-----|
| 🔴 | 🟠 | 🟡 | 🟢 | 🟢 |

### 熬夜（入睡时刻）
| ≤22:00 | 23:00 | 0:00 | 1:00 | 2:00 | 4:00 | 6:00+ |
|--------|------|------|------|------|------|-------|
| 🟢 | 🟢 | 🟡 | 🟡 | 🟠 | 🔴 | 🔴 |

## 操作

| 操作 | 说明 |
|------|------|
| ＋ 手动添加 | 选日期 + 入睡/起床时间，自动算时长 |
| ⬇ 导出 | 下载 JSON 备份 |
| ⬆ 导入 | 合并之前导出的 JSON（跳过重复） |
| 🌗 主题 | 白天/夜间模式切换 |

## 技术

纯前端单 HTML 文件，localStorage 存储，无服务器依赖。
