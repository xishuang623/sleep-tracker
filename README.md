睡眠追踪器 v2 — 使用说明

📱 安装
用手机浏览器打开页面 → 会自动弹出「添加到主屏幕」→ 点确定就成了一个 App 图标，离线也能用。

🌙 日常使用（两键操作）
操作	什么时候按	效果
😴 睡觉	准备睡了	记录入睡时间，按钮变灰，顶部显示「已睡 X 小时 Y 分」实时计时
☀️ 起床	醒来第一件事	自动算出睡了多久，生成一条当天记录
⚠️ 中午 12 点前入睡，记录归到前一天。同一天只能有一条记录，重复会提示替换。

📊 查看数据
区域	说明
时长 / 熬夜切换	顶部分类按钮，切日历的显示模式
月度日历	每个有记录的日期会着色。点格子 → 弹窗看详情 + 删除
📅 年度总览	12 列 × 31 行矩阵，一眼看全年。点格子同样弹详情
颜色含义	时长：红→绿（短→长）；熬夜：绿→红（早→晚）
🎨 颜色刻度
时长：
≤2h 🔴 · 4h 🟠 · 6h 🟡 · 7h 🟢 · 8h+ 🟢

熬夜：
≤22:00 🟢 · 23:00 🟢 · 0:00 🟡 · 1:00 🟡 · 2:00 🟠 · 4:00 🔴 · 6:00+ 🔴

➕ 手动添加
底部「＋ 手动添加」→ 选日期 + 入睡/起床时间 → 自动算时长 → 添加。

🔄 导入/导出
⬇ 导出：下载 JSON 文件备份
⬆ 导入：选之前导出的 JSON 文件合并进来（不重复）
🌗 主题切换
Tab 栏右侧 ☀️/🌙 按钮，点一下切白天/夜间模式，偏好自动保存。
